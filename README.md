# First Boot Linux

![First Boot Linux screenshot](docs/Screenshot.png)

A minimal **first-boot chooser** for PCs and laptops: sellers pre-install it; buyers pick a real Linux distribution on first power-on, then First Boot steps aside.

## What it is for

When someone unboxes a machine, they should not be locked into an operating system they never chose. First Boot Linux is a thin environment whose only job is:

1. Bring up the network (if needed).
2. Show a small set of recommended distros already on disk (configured by the retailer).
3. Offer other distros to download.
4. Install the chosen system and replace this environment.

It is not meant to be a general-purpose desktop, live USB toolkit, or network boot menu. It is a **pre-installed, first-run chooser** aimed at retail and small OEM workflows.

## Who it is for

| Audience | Why |
|----------|-----|
| **PC / laptop sellers & small OEMs** | Ship hardware with real distro choice without imaging one OS per order. |
| **Independent refurbishers & shops** | Offer a clean Linux path out of the box without forcing any single distro on every customer. |
